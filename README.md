# counterfeit-note-detector
Currency Note Authenticator is a web-based assistant that helps verify banknotes. Upload a photo and a machine learning model predicts whether the note is real or fake, with a confidence score. It uses OpenCV for image features, scikit-learn for classification and Flask for the web interface. Deployable on Render

# Note Check: Fake Currency Detection

A machine learning web app that checks a photo of a currency note and predicts whether it is **real or fake**, with a confidence score.

**Live demo:** _add your Render link here_

> **Disclaimer:** this is an educational screening aid, not proof of authenticity. A normal camera cannot capture UV, watermark or security-thread features. When in doubt, verify the note with a bank.

## How it works


Input image -> Preprocessing -> Feature extraction -> ML model -> Real / Fake -> Decision


1. **Input:** the user uploads or captures a photo of a note.
2. **Preprocessing (OpenCV):** resize, denoise, convert to grayscale.
3. **Feature extraction:** colour histograms, Canny edge density, LBP texture, Laplacian sharpness, FFT high-frequency ratio and HOG shape features.
4. **Model (scikit-learn):** four models are compared with 5-fold cross-validation; the best one is saved with Joblib.
5. **Decision:** the app returns a verdict and confidence. Blurry photos get a "retake" message, and low-confidence results are flagged for manual verification instead of guessing.

## Run locally

```
python -m venv venv
venv\Scripts\activate          # Windows   (Mac/Linux: source venv/bin/activate)
pip install -r requirements.txt

python generate_demo_data.py --n 200   # skip if you have a real dataset
python -m src.train --rebuild
python app.py                          # open http://127.0.0.1:5000
python -m pytest -q                    # run tests
```

## Dataset

The dataset folder is not committed. To reproduce:

- **Demo:** `python generate_demo_data.py` creates synthetic note images so the project runs end to end. Accuracy on this data does not reflect real-world performance.
- **Real data:** put real note photos in `dataset/real` and counterfeit or reprinted ones in `dataset/fake`, then retrain.

## API

`POST /api/predict` with a multipart field named `image`.

json
{
  "status": "ok",
  "label": "real",
  "confidence": 96.4,
  "p_real": 96.4,
  "message": "Likely real.",
  "details": { "sharpness": 88.2, "edge_density": 0.0412 }
}
'''

'status` is `ok`, `uncertain` (low confidence) or `retake` (blurry photo). `GET /health` returns the service status.

## Limitations and future work

- Trained on limited data; real-world accuracy depends on the dataset and photo quality.
- Only visible-light features are analysed.
- Next steps: analyse security regions separately (thread, serial number, portrait), add data augmentation, compare against a CNN (PyTorch or TensorFlow), and add scan history.
